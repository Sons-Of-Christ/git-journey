⚠ Identified Risks in This Flow

⚠ Identified Risks in This Flow

  • Back-dated leave applications — system may not prevent employees from applying for past dates
  • Public holiday handling — if a holiday falls within a leave period, the system must exclude it from balance deductions
  • Concurrent approvals — if two managers approve the same request simultaneously, a race condition could cause double processing
  • Notification delivery is assumed but not verified in the demo environment

⚠ Identified Risks in This Flow

  • Same candidate added to the same vacancy twice — system should detect and prevent duplicates
  • Vacancy closed while candidates are still in the pipeline — their status and history must be preserved
  • No confirmation observed when moving candidates backward in the pipeline
  • Positions count decrement on hire is assumed — not confirmed if system enforces a hard cap when all positions are filled
