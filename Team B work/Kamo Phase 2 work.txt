Activity Part 3 – Positive Test Case Design
Focus on valid system behavior.
Examples:
Valid login
Create employee successfully
Apply leave successfully
Add recruitment candidate
Update profile information
 
Deliverable:
Positive Test Case Suite 
 
Activity Part 4 – Negative Test Case Design
Focus on system failures and validation.
Examples:
Invalid login credentials
Empty username/password
Invalid email format
Missing mandatory fields
Duplicate employee creation
 
Deliverable:
Negative Test Case Suite 

Activity Part 6 – Data-Driven Test Case Design
Each test case must include:
Valid data set
Invalid data set
Edge case data
Examples:
Login Data:
Valid: Admin / admin123
Invalid: Admin / 12345
Empty: blank fields
 
Deliverable:
Test Data Linked Test Cases

Activity Part 10 – Priority Assignment
Each test case must be labeled:
High Priority
Core business functionality
Medium Priority
Important but not critical
Low Priority
UI/edge validations
 
Deliverable:
Prioritized Test Case Register
